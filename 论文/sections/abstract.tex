% ==================== 摘要专用页 ====================
\begin{center}
  {\zihao{3}\heiti 基于YOLOv8与极值理论的集装箱破损智能检测模型}
\end{center}

\vspace{1.5em}

\noindent{\heiti\zihao{-4} 摘要：}

\zihao{-4}
针对集装箱外表面破损的智能检测问题，本文构建了“检测—分类—评估”一体化的计算机视觉建模框架，依次解决破损有无判别（问题一）、破损定位与类别识别（问题二）以及模型的多维度评估（问题三）三项任务。

对于问题一，考虑到训练集全部为含破损图像、缺乏无破损负样本，直接训练二分类网络难以刻画“无破损”类别。本文提出基于极值理论（Extreme Value Theory, EVT）的开放集判别模型：利用训练好的检测网络提取每幅图像的最大检测置信度作为统计量，依据 Fisher--Tippett--Gnedenko 定理以二参数 Weibull 分布对其极值分布进行建模，并以分布的累积概率定义缺陷概率；进一步通过验证集上 F1 分数最大化确定最优分类阈值。最终模型在测试集上判别出 352 幅破损图像与 61 幅无破损图像，且判决阈值等价于约 0.34 的置信度水平，与检测结果保持统计一致性。

对于问题二，本文基于 YOLOv8 构建缺陷定位与分类模型。针对 Hole（破洞）类样本占比仅 11.8\% 的类别不平衡问题，采用针对性数据增强策略（含 Copy-Paste 与 Mosaic 等）与类别均衡设计；针对训练集无负样本导致背景误检的问题，从训练图像无标注区域裁剪构造 600 幅负样本参与训练。三组对照实验表明：骨干网络升级（YOLOv8n$\to$YOLOv8s）与数据增强策略使验证集 mAP@0.5:0.95 由 0.190 提升至 0.212，消融进一步表明增益主要来自骨干容量提升；引入负样本训练的最终模型在验证集上达到 mAP@0.5 = 0.405、mAP@0.5:0.95 = 0.205，且 600 幅负样本在问题一判别中取得最高的置信度分布分离度（Weibull 形状参数 $k=3.064$），检测结果按竞赛要求输出至 test\_result.csv。

对于问题三，本文从检测精度、分类性能、消融实验、鲁棒性、推理效率与错误分析六个维度对模型进行系统评估。结果表明：最终模型参数规模约 11.16 M，在 NVIDIA GeForce RTX 4070 Laptop GPU 上单幅 640$\times$640 图像平均推理耗时 8.87 ms（约 113 FPS），满足港口实时巡检需求；对误检与漏检案例的归因分析进一步揭示了小目标与类间外观相似是当前主要误差来源，为后续优化指明了方向。
