# 各阶段详细检查清单

## 阶段一：问题分析与假设

- [ ] 赛题 PDF 通读至少两遍
- [ ] 每个子问题标注数学类型（分类/回归/优化/预测/评价）
- [ ] 每个子问题识别核心困难（数据缺失？不平衡？无标注？）
- [ ] 明确输出格式要求（CSV 列名、坐标格式、精度要求）
- [ ] 建立 5–7 条假设，每条有文献或常识支撑
- [ ] 画出技术路线图，明确问题间依赖关系
- [ ] 确定解题顺序（先易后难 / 先检测后推断）
- [ ] 产出 `解题方案.md`

## 阶段二：数据预处理与导入

- [ ] 统计样本总量、类别分布、缺失率
- [ ] 建立「真实数字清单」（后续论文所有数字从此取用）
- [ ] 检查异常值和重复样本
- [ ] 分层抽样划分训练/验证集（seed=42）
- [ ] 按需构造负样本或做数据增强
- [ ] 格式转换完成（YOLO/COCO/CSV）
- [ ] 数据配置文件就绪（dataset.yaml 等）
- [ ] EDA 可视化生成（类别柱状图、分布直方图）

## 阶段三：模型构建

- [ ] 选定基线模型并给出选型理由
- [ ] 至少设计一个有数学推导支撑的创新点
- [ ] 核心公式推导完整（定义 → 定理 → 证明）
- [ ] 所有符号在符号说明表中列出
- [ ] 损失函数 / 目标函数公式明确
- [ ] 创新点论证链条完整（缺陷 → 分析 → 改进 → 公式）

## 阶段四：模型求解与算法实现

- [ ] 训练脚本使用 argparse 管理超参数
- [ ] 随机种子固定（seed=42）
- [ ] 消融实验设计完成（每次只变一个量）
- [ ] 训练日志完整保存（results.csv + args.yaml）
- [ ] 最优模型权重保存（best.pt / best.pth）
- [ ] 测试集预测结果生成
- [ ] 提交文件格式对齐赛题要求（列名、顺序、扩展名）
- [ ] 人工抽查若干预测样本

## 阶段五：结果验证与敏感性分析

- [ ] 计算全局指标（mAP / Accuracy / RMSE 等）
- [ ] 计算细粒度指标（逐类 / 逐场景）
- [ ] 消融实验对比表格制作完成（含 Δ 列）
- [ ] 推理速度/参数量等效率指标记录（注明硬件）
- [ ] 跨配置一致性验证（如适用）
- [ ] 关键参数敏感性分析完成
- [ ] 鲁棒性测试完成或标注为「设计/展望」

## 阶段六：可视化与报告生成

- [ ] 所有可视化图表使用中文字体（SimHei）
- [ ] 论文工程目录搭建完成
- [ ] 摘要单页，700-900 字，含关键数字
- [ ] 每张图/表编号连续，正文中被引用
- [ ] 图题在下方、表题在上方
- [ ] 公式编号连续，\eqref 引用
- [ ] 参考文献 GB/T 7714 著录，\cite 一一对应
- [ ] 全文无身份/学校信息
- [ ] 电子版不含承诺书/编号页
- [ ] 附录含全部可运行源代码
- [ ] XeLaTeX 二次编译无 undefined reference
- [ ] 正文 ≤ 20-25 页
- [ ] PDF 大小 ≤ 20 MB
