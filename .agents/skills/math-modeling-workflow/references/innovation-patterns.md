# 数学建模常见创新模式与数学工具速查

## 创新模式分类

### 模式一：损失函数改进
**适用**：分类/检测任务中存在类别不平衡、困难样本等问题。

| 问题 | 传统方法 | 改进方向 | 数学工具 |
|:--|:--|:--|:--|
| 类别不平衡 | 固定权重交叉熵 | 数据驱动的自适应权重 | Wasserstein 距离、有效样本数 |
| 困难样本 | 均等对待所有样本 | 聚焦困难样本 | Focal Loss 调制因子 |
| 标签噪声 | 硬标签 | 标签平滑 / 软标签 | KL 散度、温度缩放 |

**创新链条范例**（WD-Focal Loss）：
```
Focal Loss 的 α 需人工设定
  → 证明固定 α 导致梯度饥饿
  → 引入最优传输理论中的 W₁ 距离
  → W₁ 度量类别特征分布偏移
  → Sigmoid(β · W₁) 映射为自适应权重
  → 统一公式：L = -Σ σ(β·W₁(c)) · (1-p)^γ · log(p)
```

### 模式二：开放集/零样本推断
**适用**：训练集缺乏某类样本（如无负样本）。

| 问题 | 方法 | 数学工具 |
|:--|:--|:--|
| 无负样本二分类 | 极值理论 (EVT) | Fisher-Tippett-Gnedenko 定理、Weibull 分布 |
| 异常检测 | 密度估计 | GMM、KDE、孤立森林 |
| 分布外检测 | 能量评分 / MSP | Softmax 概率、Mahalanobis 距离 |

**创新链条范例**（EVT 分类器）：
```
训练集全为正样本，无法训练二分类器
  → 转化为开放集推断问题
  → 检测器最大置信度作为统计量
  → Fisher-Tippett-Gnedenko 定理保证极值收敛
  → Weibull 分布拟合（MLE 估计参数）
  → CDF 计算缺陷概率
  → F1 最大化搜索最优阈值
```

### 模式三：多目标/多准则融合
**适用**：评价/排序/决策类赛题。

| 方法 | 适用场景 | 核心公式 |
|:--|:--|:--|
| AHP 层次分析法 | 专家主观权重 | 判断矩阵 → 特征向量 → 一致性检验 |
| 熵权法 | 数据客观权重 | 信息熵 → 差异度 → 归一化权重 |
| TOPSIS | 多方案排序 | 正负理想解 → 欧氏距离 → 贴近度 |
| 组合权重 | 主客观融合 | α·w_AHP + (1-α)·w_entropy |

### 模式四：优化求解策略
**适用**：规划/调度/选址/路径类赛题。

| 问题规模 | 推荐方法 | 工具 |
|:--|:--|:--|
| 小规模（< 100 变量） | 精确求解 | Gurobi / CPLEX / PuLP |
| 中规模（100-1000） | 松弛 + 分支定界 | OR-Tools / SCIP |
| 大规模（> 1000） | 元启发式 | 遗传算法 / 模拟退火 / 蚁群 |
| 连续优化 | 梯度方法 | Adam / L-BFGS / 拉格朗日乘子 |

---

### 模式五：时序预测增强
**适用**：预测/预报类赛题。

| 改进方向 | 方法 | 创新点 |
|:--|:--|:--|
| 特征工程 | 小波分解 + 多尺度重构 | 分频段建模 |
| 模型融合 | ARIMA + LSTM + XGBoost | 异质模型 Stacking |
| 不确定性量化 | 分位数回归 / MC Dropout | 预测区间而非点估计 |
| 外部变量 | 格兰杰因果检验筛选 | 数据驱动变量选择 |

## 常用数学工具速查

| 工具 | 用途 | 关键公式/定理 |
|:--|:--|:--|
| Wasserstein 距离 | 度量分布差异 | W₁(μ,ν) = inf ∫ d(x,y) dπ |
| KL 散度 | 分布相似度 | D_KL(P‖Q) = Σ P(x) log(P(x)/Q(x)) |
| Fisher 信息矩阵 | 参数估计精度 | I(θ) = -E[∂²logL/∂θ²] |
| Weibull 分布 | 极值/寿命建模 | f(x;k,λ) = (k/λ)(x/λ)^{k-1} exp(-(x/λ)^k) |
| Kantorovich 对偶 | 最优传输简化 | W₁ = sup_{‖f‖_L≤1} E_μ[f] - E_ν[f] |
| Focal Loss | 困难样本聚焦 | FL = -α(1-p)^γ log(p) |
| IoU / GIoU / CIoU | 检测框回归 | IoU = |A∩B| / |A∪B| |
| F1 Score | 分类平衡指标 | F1 = 2PR/(P+R) |
| AHP 一致性 | 权重可靠性 | CR = CI/RI < 0.1 |
| 拉格朗日乘子 | 约束优化 | L(x,λ) = f(x) + Σλᵢgᵢ(x) |
