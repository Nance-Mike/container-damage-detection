# 论文各章节写作模板与范例

## 摘要写作模板

```
本文针对 [问题领域] 问题，建立了 [方法体系] 的数学模型。

针对问题一（[问题类型]），[方法简述]。[核心数学表达]。结果表明 [关键数字]。

针对问题二（[问题类型]），[方法简述]。[改进点及其数学依据]。实验结果表明 [关键指标及提升幅度]。

针对问题三（[问题类型]），[评估框架简述]。[核心结论及数字]。

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

**字数**：700–900 字。每个问题一段，按「方法 + 结果」结构。关键数字必须与正文表格一致。

---

## 问题重述写作要点

- 用自己的语言复述，**不抄原题**。
- 分为「问题背景」和「问题提出」两个小节。
- 背景段强调领域痛点和研究意义，可引用 1-2 篇文献。
- 提出段按编号列出子问题，附输出格式要求。

---

## 问题分析写作要点

- 每个子问题单独一小节分析。
- 重点说明：问题性质 → 核心困难 → 建模切入点。
- 末尾用一张技术路线图串联全文逻辑。
- 技术路线图用 TikZ 绘制，宽度用 `\resizebox{\textwidth}{!}{...}` 控制。

---

## 模型假设写作要点

- 5–7 条，用编号列表。
- 格式：「假设 [内容]。」
- 每条假设后可加简要理由或引用。
- 典型假设类型：
  1. 数据质量假设
  2. 分布假设（i.i.d.）
  3. 标注/测量准确性假设
  4. 类别/变量完备性假设
  5. 模型输出可解释性假设
  6. 特征空间连续性/可分性假设

---

## 模型建立写作要点

- 按「问题形式化 → 模型定义 → 公式推导 → 求解算法」组织。
- 核心公式用 `equation` 环境编号，关键公式用 `\boxed{}`。
- 使用 `theorem`、`definition`、`lemma` 环境组织数学内容。
- 每个公式后面必须解释符号含义。

范例结构：
```latex
\subsection{问题描述与建模思路}
% 用自然语言描述问题的数学本质

\subsection{模型建立}
\begin{definition}[xxx距离]
...
\end{definition}

\begin{theorem}[xxx定理]
...
\end{theorem}

由此推导得到本文核心公式：
\begin{equation}
\boxed{ L = ... }
\end{equation}

\subsection{求解算法}
% 算法伪代码或流程描述

\subsection{结果与分析}
% 表格 + 结论文字
```

---

## 结果分析写作要点

- 用三线表（`booktabs`）呈现指标。
- 表题在上方，五号黑体。
- 加粗最优值，用 `+X.X%` 标注提升。
- 消融表必须有 Baseline 行和 Δ 列。
- 分析文字紧跟表格，指出「是什么 → 为什么 → 意味什么」。

---

## 模型评价写作要点

分三小节：
1. **优点**：3–4 条，结合实验结果论证。
2. **缺点**：2–3 条，如实指出瓶颈，体现学术诚实。
3. **推广**：列出可迁移的应用场景，引用相关领域文献。

---

## 参考文献著录范例（GB/T 7714）

```latex
% 期刊论文 [J]
\bibitem{key} 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.

% 会议论文 [C]
\bibitem{key} 作者. 题名[C]//会议名. 地点: 出版者, 年: 页码.

% 专著 [M]
\bibitem{key} 作者. 书名[M]. 出版地: 出版社, 年.

% 网络资源 [EB/OL]
\bibitem{key} 作者. 标题[EB/OL]. (发布日期). 网址.

% 预印本
\bibitem{key} 作者. 题名[EB/OL]. arXiv preprint arXiv:XXXX.XXXXX, 年.
```

---

## 附录写作要点

- 附录用 `\appendix` 切换编号为 A、B、C...
- 附录 A：主要源程序（文件清单表 + lstinputlisting 或 lstlisting）
- 附录 B：补充推导（正文放不下的详细证明）
- 源代码中的 Unicode 符号（∈ ≈ σ → 等）替换为 ASCII，避免 listings 缺字形。
- 运行环境说明放在附录 A 开头。
