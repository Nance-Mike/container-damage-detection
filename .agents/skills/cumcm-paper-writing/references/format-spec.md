# 国赛论文格式规范要点与排版约定

## 官方规范（全国组委会修订稿，以当年发布文本为准）

1. 白色 A4 纸，上下左右页边距至少 2.5 cm，左侧装订。
2. 纸质版第 1 页为承诺书，第 2 页为编号专用页（内容与格式以组委会当年提供的模板为准）。
3. 第 3 页为摘要专用页：含标题与关键词，不译英文；必须单独一页且不超过一页；从该页起在页脚中部用阿拉伯数字连续编页码。
4. 正文从第 4 页开始，不要目录，篇幅尽量控制在 20 页以内。
5. 附录页数不限，至少包含全部可运行源程序；缺少必要源码或源码不可运行可能被取消评奖资格。
6. 电子版论文不得包含承诺书与编号专用页（第一页即摘要页），格式为 PDF 或 Word，大小不超过 20 MB。
7. 正文与附录不得出现任何显示参赛队身份、学校与赛区的信息。
8. 引用他人成果须在正文标注并按科技论文规范（GB/T 7714）著录参考文献。

## 一等奖论文通行排版（本模板采用）

| 元素 | 约定 |
| --- | --- |
| 论文题目 | 三号黑体，居中 |
| 一级标题 | 四号黑体，居中，中文编号（一、二、…） |
| 二级/三级标题 | 小四黑体，左对齐 |
| 正文 | 小四宋体，1.4–1.5 倍行距 |
| 图题 | 图下方居中，五号黑体，按章编号（图5-1） |
| 表题 | 表上方居中，五号黑体，按章编号（表5-1） |
| 图表内文字 | 五号宋体 |
| 公式 | 居中，编号右对齐，文中用 `\eqref` 引用 |
| 页码 | 页脚中部，无页眉 |
| 参考文献 | 五号字，GB/T 7714 著录 |

## 编译环境与常见坑

- 引擎：XeLaTeX + ctex（`xelatex main.tex` 至少两次以解析引用与文献编号）。
- 字体：中文 SimSun/SimHei/FangSong，西文 Times New Roman；用 fontspec 显式设置。
- MiKTeX 首次运行需要在用户目录建配置；沙箱内若报 `CreateDirectoryW` 拒绝访问，需以提权方式运行或把 MiKTeX 用户目录指到可写位置。
- 中文加粗用 `\heiti`，不要用 `\textbf`（SimSun 无粗体字形）；SimSun 无斜体，定理/定义环境应使用直立正文字体。
- listings 展示含中文的源码时，Unicode 数学符号（∈ ≈ σ → 等）会缺字形，先把源码副本中的符号替换为 ASCII（in、~、sigma、->）。
- 行内长 `\texttt{...}` 会撑破行宽：拆成多个 `\texttt{...}` 片段，或插入 `\allowbreak`/`\hspace{0pt}`。
- TikZ 流程图超宽时用 `\resizebox{\textwidth}{!}{...}` 包裹。
- 页数控制：行距、图宽、`[H]` 浮动位置都会显著影响页码，正文以 20–25 页为目标。
