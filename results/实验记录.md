### 批2 过程修正（2026-08-13）

### 批2 v1 全量结果（runs/exp_wd_focal，2026-08-13，150 轮完成）
- 最终 mAP50-95 = 0.0668（基线 0.205）；best mAP50-95 = 0.054 @ep70，mAP50 = 0.135 @ep70
- 失败机制（清晰可复现）：训练后期各类 W1 距离相对自适应 τ 变大，α 经 sigmoid 饱和到 ≈1
  （负样本权重 1-α → 0），模型失去背景抑制 → 最后几轮验证 Rusty 召回虚高 0.635、精确率 0.015
- 结论：WD-Focal v1 端到端失败，根因是 α 无上限导致负样本损失消失，而非 Wasserstein 距离本身
- 修复：α 限幅 [0.25, 0.75]（alpha_min/alpha_max），已启动 v2（runs/exp_wd_focal）

### 批2 v2 最终结果（runs/exp_wd_focal，2026-08-13，150 轮完成）
- 训练最优：mAP50-95 = 0.104 @ep133（P=0.307，R=0.279）
- 独立验证（runs/exp_eval/wd_focal_v2/val_summary.json）：map50 = 0.224，map50-95 = 0.103
  - 逐类 AP50-95：Dent 0.111 / Hole 0.128 / Rusty 0.069
  - 逐类召回：Dent 0.281 / Hole 0.342 / Rusty 0.207
- 基线对照（improved_with_neg）：map50-95 = 0.204，Dent 0.295 / Hole 0.190 / Rusty 0.129
- 结论（WD-Focal 端到端失败，按止损规则收尾）：
  1. v1（α 无上限）在 ep60-70 崩塌（α→1 使负样本损失归零）；v2（α 限幅 [0.25,0.75]）避免崩塌但整体显著低于基线（约减半）
  2. 相对排序证据：Hole/Dent 的 AP50-95 比由基线的 0.64 升至 v2 的 1.15 —— Wasserstein 加权确实把更多权重给了 Hole（"补谁"=Hole）
  3. 失败主因：聚焦损失下分类分支有效梯度占比过低（cls/box 损失比远小于基线），整体检测能力下降；调参空间（γ、损失尺度、α 范围）仍存在，列为后续工作，不再投入 GPU
