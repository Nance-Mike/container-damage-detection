# 选题D：基于计算机视觉的集装箱智能破损检测 — 解题方案

## 一、赛题核心解读

本题本质上是一个**工业缺陷检测**问题，包含三个递进层次：

| 问题 | 任务类型 | 核心输出 |
|------|---------|---------|
| 问题1 | 图像分类（二分类） | 有缺陷 / 无缺陷 |
| 问题2 | 目标检测 + 实例分割 | 缺陷位置 + 缺陷类型 |
| 问题3 | 模型评估 | 多维度量化评价 |

**关键洞察**：三个问题不是孤立的。最优策略是用**一个检测模型同时解决问题1和问题2**——如果检测模型在图片中发现了任何缺陷目标，则问题1的答案就是"有缺陷"；同时检测框和类别标签直接给出问题2的答案。这样既节省工作量，又保证两个问题的一致性。

---

## 二、数据集概况

- **总量**：3713 张图片（训练集 3300 + 测试集 413）
- **图片尺寸**：640 × 640 像素
- **标注格式**：YOLO 标准格式（class_id, x_center, y_center, width, height，均为归一化值）
- **三类缺陷**：
  - Class 0 — Dent（凹陷）：3934 个标注框，占比 49%
  - Class 1 — Hole（破洞）：946 个标注框，占比 12%（**严重不足**）
  - Class 2 — Rusty（锈蚀）：3158 个标注框，占比 39%
- **多目标**：训练集中 1681 张图（51%）包含多个缺陷
- **注意**：训练集中所有图片都含缺陷，没有"无缺陷"负样本

## 三、分阶段解题计划

### 阶段 0：环境搭建与数据探索（0.5 天）

**目标**：搭建开发环境，深入理解数据特征。

1. 安装 Python 环境 + PyTorch + ultralytics（YOLOv8/v11）
2. 编写数据探索脚本：
   - 随机可视化 50 张训练图片及其标注框
   - 统计各类缺陷的标注框面积分布（大/中/小目标占比）
   - 统计每张图的缺陷数量分布
   - 分析图片的亮度、对比度、色彩分布
3. 输出数据探索报告（图表），为论文"数据分析"部分积累素材

**交付物**：数据探索 notebook + 可视化图表

---

### 阶段 1：数据预处理与增强（0.5 天）

**目标**：解决类别不平衡、提升模型泛化能力。

1. **构造负样本（关键步骤）**：
   - 训练集中没有无缺陷图片，但问题1需要区分有/无缺陷
   - 方案A：从训练图片中裁剪明显无缺陷的区域（如天空、地面背景）
   - 方案B：从网络搜集正常集装箱图片
   - 方案C：将部分训练图片随机擦除缺陷区域，生成"伪无缺陷"样本
   - 建议：至少构造 500-1000 张负样本

2. **数据增强策略**（针对题目提示的难点）：
   - 光照变化：随机亮度/对比度调整、HSV 色彩空间扰动
   - 阴影/污渍：随机添加阴影遮罩、噪声
   - 尺度变化：随机缩放（应对大小不一的缺陷）
   - 几何变换：水平翻转、随机旋转（±15°）
   - Mosaic / MixUp 增强（YOLO 内置支持）
   - 针对 Hole 类（样本少）：额外的过采样或 Copy-Paste 增强

3. **数据集划分**：
   - 从 3300 张训练图中划出 10%-15% 作为验证集
   - 确保各类别在验证集中分布均匀

**交付物**：增强后的数据集 + 增强效果对比图

---

### 阶段 2：问题2 — 目标检测模型构建（1.5-2 天）

**目标**：训练一个高精度的缺陷检测模型。

**推荐技术路线**（由易到难，逐步迭代）：

**基线模型（Baseline）**：
- 使用 YOLOv8n / YOLOv8s 预训练权重，在自定义数据集上微调
- 训练 100-200 epochs，记录 mAP、Precision、Recall
- 这一步的目的是跑通流程、建立基准

**改进方向**（选择 2-3 个重点改进，写入论文）：

1. **注意力机制**：在 Backbone 中嵌入 CBAM / SE / CA 注意力模块，增强对小目标（如细小裂缝）的特征提取
2. **多尺度特征融合改进**：修改 Neck 结构（如 BiFPN、AFPN），提升对不同尺寸缺陷的检测能力
3. **损失函数优化**：使用 Focal Loss 或 Class-Balanced Loss 缓解类别不平衡
4. **Backbone 替换**：尝试更轻量的 Backbone（如 MobileNetV3、GhostNet）或更强的 Backbone（如 ConvNeXt）
5. **小目标检测增强**：增加 P2 检测头（160×160 特征图），专门检测微小缺陷

**训练技巧**：
- 使用预训练权重（COCO 预训练）
- 学习率：余弦退火调度
- 早停策略（Early Stopping）
- 多尺度训练（Multi-scale Training）

**交付物**：训练好的模型权重 + 训练曲线 + 检测结果可视化

---

### 阶段 3：问题1 — 分类模型（0.5 天）

**目标**：判断图片是否存在缺陷。

**方案A（推荐）：从检测模型推导**
- 直接用阶段2的检测模型对图片做推理
- 若检测到任何目标（置信度 > 阈值）→ 有缺陷
- 若无检测结果 → 无缺陷
- 优点：与问题2共享模型，逻辑一致
- 需要调优：置信度阈值（通过验证集上的 ROC 曲线确定最优阈值）

**方案B：独立分类模型**
- 使用 ResNet50 / EfficientNet-B0 做二分类
- 输入：整张图片 → 输出：有缺陷概率
- 可以结合检测模型做集成（Ensemble）

**方案C：双模型融合**
- 检测模型 + 分类模型投票
- 论文中可以对比三种方案的效果

**交付物**：分类结果 + ROC 曲线 + 混淆矩阵

---

### 阶段 4：问题3 — 模型评估（1 天）

**目标**：从多个维度全面评估模型。

**评估维度**：

1. **检测精度评估**：
   - mAP@0.5、mAP@0.5:0.95（COCO 标准）
   - 各类别的 Precision、Recall、F1-Score
   - PR 曲线

2. **分类性能评估**（问题1）：
   - Accuracy、Precision、Recall、F1
   - ROC 曲线 + AUC 值
   - 混淆矩阵

3. **鲁棒性评估**（论文亮点）：
   - 对测试图片施加不同干扰（加噪声、调亮度、加模糊），观察性能下降幅度
   - 不同天气/光照条件下的表现
   - 不同缺陷尺寸下的检测率

4. **效率评估**：
   - 推理速度（FPS）
   - 模型参数量（Params）和计算量（FLOPs）
   - 与基线模型的对比

5. **消融实验**（Ablation Study）：
   - 逐一移除改进模块，验证每个改进的贡献
   - 例如：Baseline → +注意力 → +改进Neck → +Focal Loss

6. **错误分析**：
   - 收集误检（False Positive）和漏检（False Negative）案例
   - 分析失败原因（遮挡、相似外观、极小目标等）
   - 可视化典型失败案例

**交付物**：评估报告 + 对比表格 + 消融实验图表

## 七、风险提醒

1. **类别不平衡是最大挑战**：Hole 类只有 946 个样本，检测效果可能明显弱于其他两类，必须重点处理
2. **无缺陷样本缺失**：训练集全是缺陷图片，问题1的分类需要额外构造负样本
3. **时间管理**：不要花太多时间在模型调参上，论文写作同样重要
4. **结果可复现**：固定随机种子，保存所有实验配置
5. **test_result.csv 格式**：严格按照要求的格式输出（image_id, class_id, x_center, y_center, width, height）
